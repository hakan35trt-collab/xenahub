# XENAHUB PWA

Bagimsiz, profesyonel, yuksek performansli PWA uygulamasi.

## Kurulum
```bash
npm install
```

## Gelistirme
```bash
npm run dev
```

## Build
```bash
npm run build
npm run server:build
```

## Production
```bash
npm start
```

## Railway Deploy
Railway uzerinde otomatik deploy icin `railway.json` dosyasi hazir.
